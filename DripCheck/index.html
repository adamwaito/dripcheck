Quick guide

Install DripCheck: A Progressive Web App (PWA) is essentially a website that you can install on your home screen that behaves like a regular app. To install DripCheck on iPhone, from your browser tap Share then Add to Home Screen. On Android, use the browser's install option or the address-bar install icon. On desktop, use the browser's install option or the address-bar install icon.

Drip protection: When freezing weather is forecast, letting a faucet run as a small steady drip so water keeps moving through the pipe can help prevent frozen pipes. Focus on taps connected to pipes along exterior walls, in unheated areas, or drip the faucet farthest from the water entry point. A slow drip, roughly one drop per second, or a thin trickle, is usually sufficient.
